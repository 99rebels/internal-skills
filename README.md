# Internal Skills & Tools

Private collection of skills, tools, and research infrastructure for The Skill Economy publication.

## Contents

- **content-strategy** — Research briefs, strategy docs, and reference files for the Substack newsletter
- **ecosystem-radar** — Monitors the agent skill marketplace ecosystem (ClawHub, Agensi, Cursor, etc.)
- **github-publish** — GitHub repo creation and publishing workflow
- **idea-generator** — Skill idea pipeline and tracking
